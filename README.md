
# Gym Membership SQL Analysis

## Overview
Analysis of gym membership data using SQL to identify member behavior patterns, retention trends, and revenue insights.

## Dataset
- Source: Kaggle Gym Dataset
- Records: 973
- Key columns: member_id, join_date, membership_type, attendance, revenue

## SQL Techniques Used
- Common Table Expressions (CTEs) for multi-step analysis
- Window functions (ROW_NUMBER, RANK) for member segmentation
- Date functions for retention calculations
- JOINs for combining member and attendance data
- Aggregations (SUM, AVG, COUNT) for business metrics

## Files
- `gym_analysis.sql` - All SQL queries
- `gym_dataset.csv` - Raw data
